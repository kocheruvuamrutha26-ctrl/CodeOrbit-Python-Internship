# CodeOrbit To-Do List CLI App

## Task
To-Do List CLI App for the CodeOrbit Tech Python Programming Internship.

## Features
- Add tasks
- View tasks in a numbered list
- Remove tasks
- Uses a Python list during runtime
- Uses functions to organize each feature
- Optional text-file saving/loading is included

## How to Run
```bash
python todo.py
```

## Example
```text
1. Add Task
2. View Tasks
3. Remove Task
4. Save and Exit
```
