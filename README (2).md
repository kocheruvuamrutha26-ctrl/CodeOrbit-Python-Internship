# CodeOrbit Number Guessing Game

## Task
Number Guessing Game for the CodeOrbit Tech Python Programming Internship.

## Features
- Generates a random number
- Gives "too high" and "too low" hints
- Counts attempts
- Handles invalid input
- Allows multiple rounds

## How to Run
```bash
python guessing_game.py
```

## Example
```text
I have selected a number between 1 and 100.
Enter your guess: 40
Too low! Try again.
Enter your guess: 70
Too high! Try again.
```
