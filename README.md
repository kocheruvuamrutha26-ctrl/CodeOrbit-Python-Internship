# CodeOrbit Simple Calculator

## Task
Simple Calculator for the CodeOrbit Tech Python Programming Internship.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Handles invalid numeric input using `try/except`
- Handles division by zero
- Includes comments and a function for the calculator

## How to Run
```bash
python calculator.py
```

## Example
```text
Enter first number: 20
Enter second number: 5
Enter operation: /
Result: 20 / 5 = 4
```
